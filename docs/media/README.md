# Meridian showcase media

The future-vision image is AI-generated concept artwork inspired by the existing Meridian city. It illustrates a possible visual direction, including future infrastructure, rather than a current release or an architectural plan.

The Founding District, Prismatic Gardens and Riverside Workshops images are unretouched browser screenshots captured from the public viewer at https://meridian.creeleydigital.com.au/ on 26 October 2026, Sydney time. District camera presets and the viewer’s own daylight/blue-hour controls were used. No private panels or personal files were captured. These are flat screenshots; underlying deployed model/texture source is not distributed here.

The Meridian identity began with AI-assisted visual exploration and was finished as original, scalable SVG geometry for this project. Light and dark wordmarks and a standalone mark are included. Its meridian axis, horizon and M represent orientation, continuity and a growing world. It contains no OpenAI logo, partner badge or other third-party brand mark.

Source code, current hosted-world captures and aspirational artwork are identified separately so visitors can judge the work accurately.
