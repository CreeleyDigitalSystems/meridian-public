# Security

This alpha source showcase is separate from the hosted city. Project-owned source uses Apache 2.0. Repository rules and a private vulnerability reporting channel require repository configuration before opening a public contribution process.

Do not put credentials, personal continuity, provider prompts, production world files, journals or operational diagnostics in issues, pull requests or public logs. Report a suspected disclosure privately through the repository's private vulnerability reporting feature once the owner enables it. Until then, do not publish exploit details or personal data.

The default fictional demo has no paid AI, Docker authority, production data access or deployment capability. Optional AI and execution APIs are explicit host capabilities. Request and byte limits do not establish a currency spending ceiling. Treat generated code as untrusted: use the reviewed isolated executor interface, never eval it on the host. Do not mount production data, credentials, a checkout or a Docker socket into a resident program.
